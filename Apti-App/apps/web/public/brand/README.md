# AptiQuiz brand assets

| Asset | Intended use |
| --- | --- |
| [aptiquiz-logo.png](aptiquiz-logo.png) | Original transparent horizontal logo on light backgrounds |
| [aptiquiz-logo-readme.png](aptiquiz-logo-readme.png) | Ivory-backed logo for documentation on light or dark themes |
| [aptiquiz-icon.png](aptiquiz-icon.png) | Standalone Q/check browser and compact app icon |

The original logo was selected by the user. These are the canonical deployable assets; documentation and design previews reference this directory. Use [the brand guide](../../../../../Brand.md) for usage rules and [the original prompt](../../../../../design-mocks/aptiquiz-logo/README.md) for provenance. The documentation and icon adaptations were made with built-in imagegen. These are raster PNGs, not editable vector files.

## Documentation adaptation prompt

```text
Use case: logo-brand. Image 1 is the approved AptiQuiz logo, used as an edit target. Preserve the exact orange Q/check mark and dark ink AptiQuiz wordmark, geometry, spelling, proportions and horizontal composition. Change ONLY the empty transparent background to a uniform opaque solid ivory #FDFBF7 rectangular canvas, including every hollow counter and space between letters. Clean polished flat logo on ivory, crisp edges, no speckles, no textural residue. No new elements, shadows, gradients, borders, slogans, decoration or mockups. Keep original 3:1 aspect ratio.
```

## Icon adaptation prompt

```text
Use case: logo-brand. Image 1 is the edit target: the approved AptiQuiz logo. Produce the standalone app icon by extracting ONLY the existing orange Q/check symbol from the left of this image and centering it on a square genuinely transparent canvas with 12% clear margin. Preserve the exact source geometry: orange broken circular Q ring, integrated diagonal check crossing the lower right and short detached triangular tail, exact orientation, orange color, proportions, hollow counter, and negative-space cuts. Remove the wordmark entirely. Flat crisp orange mark, no redesign, no text, no new enclosing shape, no background, shadow, texture, mockup, or new decorative element.
```
