# Architecture Decision Records

One file per decision, numbered sequentially (`0001-...`, `0002-...`). Use [`docs/Templates/ADR.md`](../Templates/ADR.md).

Only write an ADR when all three are true:

1. **Hard to reverse** — the cost of changing your mind later is meaningful.
2. **Surprising without context** — a future reader will wonder "why did they do it this way?"
3. **The result of a real trade-off** — there were genuine alternatives and one was picked for specific reasons.

If any of the three is missing, it doesn't need an ADR — a note in the relevant PR or `docs/QnA/` entry is enough.
