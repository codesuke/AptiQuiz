# CTA animation gallery

Open `index.html` in a browser to explore twelve premium CTA interaction patterns. The page loads Tailwind from its browser CDN and uses a small amount of local CSS and JavaScript for pointer-aware interactions.

Every control has a 48px minimum target, a visible keyboard focus ring, and a reduced-motion mode. The gallery is a visual prototype only; copy its selected interaction into the product component rather than linking the application to this page.
