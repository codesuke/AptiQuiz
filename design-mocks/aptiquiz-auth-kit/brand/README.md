# AptiQuiz brand assets

![AptiQuiz](../../../Apti-App/apps/web/public/brand/aptiquiz-logo-readme.png)

The authentication prototype uses the approved Q/check logo and icon from [the shared web brand directory](../../../Apti-App/apps/web/public/brand/). Follow [Brand.md](../../../Brand.md) for proportions, backgrounds, clear space, and accessible naming. Source prompts are recorded in [logo provenance](../../aptiquiz-logo/README.md).

`aptiquiz-mark.svg` is the historical orange rounded-square leaf reference. It is preserved to explain the original generated screen; current prototypes and application code do not consume it.
